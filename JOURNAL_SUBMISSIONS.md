# Journal Submissions Tracking

This is a personal archive of journal/publication submissions. Each entry is tracked with submission date and status.

## How to Add/Update Submissions

When you have a new submission or status update:

1. **Provide the information:**
   - Paper/Work Title
   - Journal/Publication Name
   - Submission Date (YYYY-MM-DD)
   - Current Status (Submitted, Under Review, Rejected, Accepted, Withdrawn, etc.)
   - Optional: Notes

2. **I will:**
   - Add it to `library/books/journal-submissions.html`
   - Commit the change with a descriptive message
   - Push to the repository

3. **You can then:**
   - Access the updated list at any time at `www.quantum-coherence-ethics.org/library/books/journal-submissions.html`
   - Track submissions without needing your phone or local files

## Format Example

```
Title: "Quantum Coherence and Ethical Agency"
Journal: Philosophy of Science
Submitted: 2026-01-15
Status: Under Review
```

Each submission is timestamped in git, creating an audit trail of all updates.
